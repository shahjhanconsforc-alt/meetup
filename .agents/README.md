# .agents

Scratch space for agent-assisted work on this repo — notes, plans, and one-off
scripts that shouldn't ship.

Excluded from the Docker image (see `.dockerignore`). Nothing here is imported by
the app; if something in this directory becomes load-bearing, it belongs in
`backend/` or `services/` instead.

Not to be confused with `Categorization_Agents_Pipeline/agents/`, which holds the
eight real classification agents and *is* application code.
